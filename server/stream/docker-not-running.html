Docker Desktop не отвечает

Программа уже пыталась запустить Docker Desktop сама и подождала пару минут — не получилось. Открой Docker Desktop из меню Пуск вручную и посмотри, не показывает ли он ошибку. Если он просто долго думает — дождись, пока иконка кита в трее перестанет "грузиться", и нажми на ярлык «Запустить трансляцию» на рабочем столе ещё раз. Если ошибка — может помочь перезагрузка компьютера.
