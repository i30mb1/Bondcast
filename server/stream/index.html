Bondcast Stream

Свой сервер для трансляций из приложения Bondcast — принимает бондинг-стрим с телефона и раздаёт его дальше. Ставится на свой компьютер в один клик.

телефон (N линков) ──▶ приём с бондингом ──▶ видеосервер ──▶ зрители / OBS Панель в браузере показывает адрес и QR для телефона.

Прежде чем скачивать

Windows при первом запуске почти наверняка покажет синий экран «Windows защитила ваш компьютер» — это стандартное предупреждение для новых программ без платной цифровой подписи, не признак вируса. Нажми «Подробнее», затем «Выполнить в любом случае».

⬇ Скачать установщик для Windows

Бесплатно. Один .exe-файл, ничего распаковывать не нужно.

Что произойдёт

  1. Запускаешь скачанный файл — мастер установки на русском.
  2. Если на компьютере ещё нет Docker Desktop — установщик поставит его сам (может попросить один раз перезагрузить компьютер — просто нажми на ярлык на рабочем столе ещё раз после перезагрузки).
  3. На рабочем столе и в меню Пуск появится ярлык «Запустить трансляцию».
  4. Открывается панель в браузере — там адрес и QR-код для телефона.

Проверь сеть прямо сейчас

определяю внешний IP…

Это тот адрес, на который телефон будет подключаться из интернета — он же появится в панели после установки. Если на компьютере включён VPN, здесь покажет адрес VPN, а не настоящий адрес роутера — на время трансляции VPN лучше выключить.

Что ставится под капотом, если интересно Внутри — Docker Desktop (бесплатный для личного использования и небольших компаний) и три контейнера: видеосервер SRS, приёмник бондинга srtla-rec и веб-панель управления ими. Исходники и ручная установка — по ссылке внизу страницы.
