Bondcast Stream

Превращает твой компьютер в приёмник видео. Телефон шлёт картинку сразу по нескольким сетям — Wi-Fi и мобильный интернет вместе, чтобы не рвалось, — а ты забираешь её в OBS и ведёшь эфир куда хочешь. Ставится в один клик.

телефон (Wi-Fi + мобильный разом) ──▶ этот компьютер ──▶ OBS ──▶ Twitch / YouTube Панель в браузере покажет код, который надо навести телефоном.
⬇ Скачать установщик для Windows

Бесплатно. Один файл, распаковывать ничего не нужно.

Windows ругнётся при первом запуске

Почти наверняка появится синий экран «Windows защитила ваш компьютер». Так она встречает любую новую программу без платной подписи разработчика — это не вирус. Нажми «Подробнее», затем «Выполнить в любом случае».

Что будет дальше

  1. Запускаешь скачанный файл — установщик на русском, соглашаешься со всем.
  2. Если на компьютере нет Docker Desktop — установщик поставит его сам. Может один раз попросить перезагрузиться: после перезагрузки просто нажми ярлык на рабочем столе ещё раз.
  3. На рабочем столе появится ярлык «Запустить трансляцию».
  4. Он откроет панель в браузере. Там будет две кнопки: «Начать стрим» и «Настроить эфир».

Нужен ли тебе вообще интернет-адрес

смотрю…

Если телефон и компьютер дома в одной Wi-Fi — этот адрес не нужен, всё заработает сразу. Он понадобится, только когда пойдёшь стримить с улицы: тогда телефон будет искать компьютер по нему, и до него надо будет открыть дорогу на роутере — панель подскажет как. Если сейчас включён VPN, здесь покажется адрес VPN, а не твой настоящий: на время стрима VPN лучше выключить.

Что ставится под капотом, если интересно Внутри — Docker Desktop (бесплатный для личного использования и небольших компаний) и три контейнера: видеосервер SRS, приёмник бондинга srtla-rec и веб-панель управления ими. Исходники и ручная установка — по ссылке внизу страницы.
